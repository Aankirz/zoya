# Media

`media_control` presses the Mac's play/pause, next and previous keys for whatever is loaded (a
browser tab or an app). It cannot choose a song: for a named song use the spotify-web or youtube
skill. Say exactly what you did ("I pressed pause"), not "Playing <song>".
